⚙️ Workflow & Operational Process

  1. Data Pipeline: Raw telco dataset ingested, processed, and stored as optimized Parquet partitions.
  2. Distributed Training: PySpark ML trains Logistic Regression and Random Forest models with class-weight handling.
  3. Tracking & Logging: Model artifacts and parameters logged directly into MLflow using proxied storage (`--serve-artifacts`).
  4. Continuous Integration: GitHub Actions automated pipeline handles remote directory provisioning, Docker image creation, and live server deployments.
  5. Serving & Observability: FastAPI dynamically pulls logged MLflow pipelines to execute real-time predictions while sending metrics to Prometheus.
